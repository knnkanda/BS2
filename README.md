# B/S 簡易分析ツール

決算短信や財務データからコピーした貸借対照表（B/S）を貼り付け、資産・負債・純資産の構成を簡単に可視化するブラウザアプリです。

## できること

- 決算短信形式の財務データを解析
- 流動資産・非流動資産、流動負債・非流動負債、資本合計を表示
- 資産合計と負債・純資産合計を比較
- 流動比率・固定比率・自己資本比率を計算
- 貸借一致チェック
- 全角・半角数字、全角カンマ、`△`によるマイナス表記に対応
- 金額単位（円・千円・百万円・億円・兆円）と通貨を指定
- 企業名、シンボル、株価、時価総額、基準日、出典URLを任意入力
- 結果を画像・JSON・Markdownで保存

## 使い方

1. 金額単位と通貨を選択します。
2. 必要に応じて企業情報、会計データの年月日、出典URLを入力します。
3. 決算短信などから貸借対照表のテキストをコピーします。
4. 入力欄に貼り付け、「データを抽出してグラフ化」をクリックします。

## 数値の扱い

複数年度の数値がある場合、各行の右端にある数値を最新のデータとして使用します。前年度・前々年の数値は分析対象外です。

```text
流動資産合計 42,824,081 38,852,813
```

この場合、右側の`38,852,813`を使用します。

科目名と数値が同じ行にある決算短信形式、および科目名と数値が別の行にある形式に対応しています。

## 指標

- 流動比率：流動資産 ÷ 流動負債 × 100
- 固定比率：非流動資産 ÷ 資本合計 × 100
- 自己資本比率：資本合計 ÷ 資産合計 × 100

## 注意事項

このツールは、コピーしたテキストを簡易的に解析するものです。科目名やデータ形式が大きく異なる場合、正しく読み取れない可能性があります。

「貸借一致チェック」は入力データから再構成した数値の比較です。会計監査や投資判断を代替するものではありません。

資産の部だけを入力した場合は、資産側のみが分析され、貸借一致チェックは成立しません。

## データの取り扱い

入力データはブラウザ上で処理されます。出典URLは結果に記録・表示するための情報であり、URL先のデータを自動取得する機能ではありません。
